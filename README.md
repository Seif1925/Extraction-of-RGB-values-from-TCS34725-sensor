# RGB Value Extraction from TCS34725 Sensor on NVIDIA Jetson Nano

This project demonstrates how to extract accurate RGB values from the TCS34725 color sensor using an NVIDIA Jetson Nano. The system leverages **sensor calibration** (via a lookup table) and **machine learning** (K-Nearest Neighbors algorithm) to improve the reliability of color detection in real-world scenarios. Below is a comprehensive guide to understanding, replicating, and extending this project.


---

## Project Overview
The TCS34725 sensor provides raw red, green, blue, and clear (RGBC) light data, but its outputs are nonlinear and environment-dependent. To address this:
1. **Sensor Calibration**: A lookup table is generated by mapping raw sensor outputs to known reference RGB values under controlled lighting.
2. **AI-Driven Correction**: A K-Nearest Neighbors (KNN) model is trained on the calibrated data to predict RGB values from raw sensor readings.


The Jetson Nano serves as the processing unit, interfacing with the sensor via I2C and running the calibration/prediction algorithms.

## Key Features
- **Lookup Table Calibration**: Compensates for sensor nonlinearities and ambient noise.
- **KNN Regression**: Maps raw sensor data to standardized RGB values with high accuracy.
- **Real-Time Visualization**: Displays extracted RGB values and their corresponding color swatches.
- **Modular Codebase**: Easily extensible for integration with robotics, IoT, or computer vision systems.

---

## Hardware Requirements
- **NVIDIA Jetson Nano** (with power supply and microSD card)
- **TCS34725 RGB Sensor** (with I2C interface)
- **Jumper Wires** (for connecting sensor to Jetson GPIO)
- **Breadboard** (optional, for prototyping)
- **Calibration Tools**: A set of reference color cards/samples for generating the lookup table.

---

## Software Dependencies
- **Python 3.6+**
- Libraries:
  - `smbus2` (for I2C communication)
  - `scikit-learn` (KNN implementation)
  - `numpy`, `pandas` (data processing)
  - `matplotlib` (visualization)
- **Jetson Nano OS**: JetPack 4.6 or later (with I2C enabled).
